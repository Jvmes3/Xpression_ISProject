The links above open each role. Apply starts an account screen. The menu at the top right lists sign-in and the other shared features. Nothing on these pages saves data.

About

Xpression is a community for creative work. After sign-in, the account role chooses the home. These files are the Sprint Cycle I designs.

Help

To run the application, follow the README in the project folder. The address to open is the one printed next to Local: in the terminal, usually http://localhost:3000.
