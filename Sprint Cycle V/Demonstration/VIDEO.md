# Sprint Cycle V demonstration video

The team records this video from the running Sprint Cycle V site. There is no in-class presentation.

Save the recording in this folder as `Sprint Cycle V Demonstration.mp4`.

If that file is too large for GitHub, replace this note with a link the instructor can open. Keep this file name so the link is easy to find.

The recording needs to show:

1. The site running.
2. A sign-in for the administrator, creator, mentor, talent scout, and moderator.
3. Activate or deactivate an account, and the status before and after.
4. Publish a piece of creative work.
5. Save structured mentor feedback.
6. Create an opportunity.
7. Update a reported piece with findings and an action, and the case before and after.
8. One invalid case, such as music with no sample link, an end date before the start date, or empty findings.
9. One screen that already worked in Sprint Cycle IV, such as the community feed or the creator search.
10. The matching rows in MySQL. The queries are in the Sprint Cycle V README.
