# Sprint archive

Use `cycle-00`, `cycle-01`, `cycle-02`, etc. for consistent sorting. Create a folder from [the sprint template](templates/sprint-template.md) for each new cycle.

| Cycle | Focus | Materials |
| --- | --- | --- |
| 0 | Team setup and technology selection | [Archive](cycle-00/README.md) |
| I | User interface design and initial application screen | [Sprint record](cycle-01/README.md) |

Each cycle owns its requirements, design artifacts, checklist, presentation, meeting notes/photos, and contribution evidence. Live source remains in `/app`, `/lib`, and `/public`. Record a final commit or tag in the sprint record to preserve the exact application version. Commit actual screenshots into that cycle when captured; do not duplicate dependencies or build output. Keep historic documents unchanged unless correcting a verified error.
