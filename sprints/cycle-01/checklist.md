# Sprint Cycle I submission checklist

- [x] Implement homepage with name, logo graphic, description, and navigation.
- [x] Create sign-in screen with fictional example users.
- [x] Create landing/navigation mockups for all five roles.
- [x] Select two meaningful use cases per role and document screen specifications.
- [ ] Verify selected use cases against the full Functional Requirements document.
- [ ] Produce and save visual screen mockups for the ten use cases.
- [ ] Capture homepage, sign-in, and all five landing screenshots.
- [ ] Choose this cycle's Scrum Master and record sprint dates.
- [ ] Record actual meetings spread throughout the sprint.
- [ ] Record at least one meaningful pushed contribution per teammate.
- [ ] Each teammate pulls and verifies the application locally.
- [ ] Finalize presentation and rehearse the application demonstration.
- [ ] Push application source and all Cycle I materials to GitHub.
- [ ] Record final commit or tag in the sprint README.
- [ ] Submit repository link, designs, presentation, and meeting documentation.

Local code and documents are prepared; unchecked items require actual team activity or additional design artifacts. Do not treat Cycle 0 contributions as Cycle I evidence.
